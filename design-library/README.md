# Visual recipes

The catalog contains Apple-inspired, Material, Fluent, Linux-inspired, glass, matte glass, neumorphism, Bento, futuristic, minimal, brutalist, flat, retro, cyberpunk, corporate, editorial, monochrome, industrial, luxury and custom recipes. Each defines description, default radius, shadow and font family guidance.

These are broad visual directions, not copies of a vendor's proprietary component library. Configuration radius overrides recipe guidance; typography selection can override the recipe family. Semantic tokens preserve contrast. The current component set shares consistent structure across recipes; richer style-specific widgets and hybrid composition are future extensions.
