# Local assets

Keep synthetic, licensed assets here when a project requires them. Do not commit private logos, uploaded screenshots, production media or large binaries by default. Reference paths belong in project configuration; asset contents are untrusted data.

Before integration, inspect file type, dimensions/aspect ratio, dominant colors, contrast/readability, placement, licensing, size and optimization opportunities. Sanitize SVG and block executable content; reject oversized or unexpected files. Image/video/3D asset rendering is agent-assisted in this release. No automatic upload, logo extraction, optimization or CDN publishing is performed.
