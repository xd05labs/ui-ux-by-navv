# Changelog

## Unreleased — licensing and clean publishing

- Added numbered publisher menus for setup, preview, new/existing repositories, sign-in, reports, help and exit; missing requirements can be downloaded/installed through the terminal using WinGet, with a terminal bootstrap option if WinGet is missing.

- Replaced the Builder's MIT notice with a source-available use license restricting additional copying, modification and redistribution, subject to necessary use copies and platform/statutory rights.
- Added explicit permission to customize and redistribute generated apps; all generator modes include its notice, and approval hashes cover licensing inputs.
- Added a self-contained Windows clean publisher with offline preview, Git ignores, credential checks, private-by-default creation, existing-link updates and isolated Git snapshots.
- Added Windows integration tests using local Git remotes; no live GitHub account operations were performed.

## 0.1.0 — 2026-11-25

- Added portable LLM entry files and a shared application-building protocol.
- Implemented adaptive discovery, typed configuration, answer provenance, checkpoints and recovery.
- Added 19 industry register blueprints, 20 style recipes and eight palettes.
- Implemented accessible semantic tokens and an offline interactive concept preview.
- Added an executable vanilla/Python WSGI/SQLite adapter with private CRUD, sessions, roles, audit history and migrations.
- Added exact-plan approval, change-impact previews, collision-safe regeneration and interrupted-generation rollback.
- Added honest quality reports, repository/generated/browser checks, CI and benchmark recording.

Broader framework generators, domain transactions, asset intelligence, external integrations, automated hosting, complete accessibility/performance audits and cross-LLM benchmark results remain future or agent-assisted work.
