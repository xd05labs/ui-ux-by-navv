# Existing-project mode

Inspect the specified directory, its instructions, Git status, manifests, source boundaries, migrations, environment examples and existing tests. Do not execute untrusted install scripts without review. Record current behavior and a baseline of checks that can actually run.

Map requested improvements onto existing components, models and deployment conventions. Propose an incremental plan, affected files, compatibility risks and rollback. Preserve unrelated code, user data, credentials and public contracts. Make scoped changes and execute the project's real checks. Update AppForge state with accepted decisions and evidence.

The generic generator deliberately refuses existing-project mode. Agent-assisted editing is required so it cannot replace an existing application with a different starter.
