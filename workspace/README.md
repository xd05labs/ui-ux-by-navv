# Local project workspace

This directory is intentionally uninitialized. Run `python -m appforge init`, then `wizard` and `plan`. The first real application should begin with discovery rather than a preselected demo.

Generated files, decisions, checkpoint history and databases are ignored by Git. Use `--workspace PATH` before a CLI command to manage another project. Sample configurations live in examples/; smoke-test artifacts live in ignored artifacts/ and do not become your default project.
